# Sponsorship & Financial Support

LibreM is an independent open-source project designed to provide modern, reliable, and accessible library technology to educational institutions worldwide without vendor lock-in or recurring proprietary licensing fees.

Sponsorship directly funds:
- Continuous maintenance and compatibility updates for Windows and Linux distributions.
- Security audits and database transaction benchmarking.
- Active development of enhanced features (Marc21/Z39.50 protocols, automated backup integrations, and multi-branch synchronization).
- Infrastructure costs for hosting documentation and release mirrors.

---

## How to Sponsor

You can support the LibreM core team through several channels:

- **GitHub Sponsors**: [github.com/sponsors/LibreM](https://github.com/sponsors/LibreM)
- **Open Collective**: [opencollective.com/librem](https://opencollective.com/librem)
- **Direct Institutional Partnerships**: For custom deployments, migration support from legacy SLiMS versions, or dedicated SLA contracts, contact `partnerships@librem.dev`.

---

## Sponsorship Tiers

### Community Supporter ($10 / month)
- Name listed in GitHub release notes and project backer wall.
- Access to supporter discussions and early preview channels.

### Institutional Sponsor ($100 / month)
- School / organization logo displayed on the official project README and website.
- Prioritized issue triaging on bug fixes and feature requests.

### Core Ecosystem Partner ($500+ / month)
- Prominent placement across all project repositories and release documentation.
- Direct quarterly roadmap alignment call with the core maintainers.
